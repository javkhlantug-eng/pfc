# pfc — Оргил ачааллын таамаг

Төвийн бүсийн эрчим хүчний системийн **маргаашийн цагийн ачаалал, оргил цаг, оргил МВт**-ыг
агаарын температур болон өмнөх ачааллаас таамаглаж, GitHub Pages дээр дашбоардаар харуулна.

## Бүтэц

| Файл | Үүрэг |
|---|---|
| `src/collect_load.py` | dis.energy.mn-ийн `generation-chart/history?date=` API-аас цагийн ачаалал татна → `data/load_hourly.csv` |
| `src/collect_weather.py` | Open-Meteo-оос Улаанбаатарын цагийн температур (түүх + таамаг) → `data/weather_*.csv` |
| `src/features.py` | Цаг, гараг, баяр, температур, халаалтын градус-цаг, ачааллын хоцрогдол |
| `src/forecast.py` | Загвар сургаж маргаашийн таамгийг гаргана → `docs/data/*.json` |
| `docs/index.html` | Дашбоард (Chart.js) |
| `data/holidays.csv` | Сарны тооллын баярууд (Цагаан сар, Чингисийн өдөр…) — жил бүр шинэчлэх |
| `src/config.py` | Цаг агаарын цэгүүд, системийн боломжит чадал (`CAPACITY_MW`) |

## Загвар

- **Цагийн муруй:** 24 цаг тус бүрийн ачаалал (gradient boosting). Оргил **цаг** эндээс гарна.
- **Өдрийн оргил:** өдрийн оргил **МВт**-ыг тусдаа загвараар таамаглана (цагийн муруйн дээд цэг бодит оргилоос системтэйгээр бага гардаг тул).
- **Хүрээ (P10–P90):** сүүлийн 90 хоногийн загварт үзээгүй алдаанаас тооцно. Медиан алдаагаар ачааллын жилийн өсөлтийн хазайлтыг засна.
- Таамгийг D өдрийн 16:23 цагт D+1-д гаргадаг тул ачааллын хоцрогдол зөвхөн бүрэн дууссан өдрүүдийг (2 ба 7 хоногийн өмнөх) ашиглана.

## Ажиллуулах

1. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, Folder = `/docs`.
2. **Actions → «Түүхэн өгөгдөл татах (нэг удаа)» → Run workflow** (≈30 мин). Эхний алхам dis.energy.mn руу хандаж болох эсэхийг шалгана.
3. Дараа нь **«Өдөр тутмын таамаг»** өдөр бүр 16:23 цагт автоматаар ажиллана.

Хэрэв dis.energy.mn гадаадын IP-г хаадаг бол Монголд байгаа компьютер дээр
[self-hosted runner](https://docs.github.com/en/actions/hosting-your-own-runners) тавьж
workflow-уудын `runs-on`-ийг `self-hosted` болгоно.

Локалаар:
```bash
pip install -r requirements.txt
python src/collect_load.py --start 2024-01-01 --skip-existing
python src/collect_weather.py --full
python src/forecast.py
python -m http.server -d docs 8000
```

> dis.energy.mn-ийн API нь албан ёсоор нийтлэгдээгүй тул бүтэц нь өөрчлөгдөж болно. Сервер рүү ачаалал багатай (өдөр бүрийн хооронд 1 секунд) татдаг.
